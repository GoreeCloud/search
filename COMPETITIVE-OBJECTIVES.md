# GoreeCloud Search — Competitive Objectives

GoreeCloud Search may learn from independent and open metasearch systems, including SearXNG, regarding configurable engines, transparent provenance, filtering, reliability, accessibility, and ownership. This comparison is a design benchmark, not a claim that those features are implemented.

Priorities: provider independence; clear Search-vs-Index boundaries; user data minimization; privacy-consented query transport; deterministic result ranking; robust URL handling; keyboard/screen-reader accessibility; and Glaze quality.

Avoid: undisclosed third-party fallback, invasive profiling, mandatory subscriptions, proprietary asset copying, and calling unvalidated source code a production service.

Current evidence is restricted to the offline result-fusion module and its repository tests.
