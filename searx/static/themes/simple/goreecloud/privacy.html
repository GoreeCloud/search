Privacy and source disclosure

This Development build of GoreeCloud Search is based on SearXNG. Only two built-in search providers are selectable in this private profile: Brave Search (the service behind Brave Browser search) and Startpage. Searching forwards terms to one or both, depending on your selection. Connected providers receive requests from the search server and can retain or use request data under their own policies. The server operator may observe client IP addresses and searches unless separate infrastructure controls protect them. This service does not guarantee anonymity.

In the included loopback-only development profile, search submission defaults to POST, remote autocomplete and metrics are disabled, and images are proxied. Operators may change these settings. An approved public deployment, complete security/privacy review, GoreeCloud Privacy Shield integration, and retention controls have not been established.

This local profile rejects automatic redirects triggered by external search bangs or first-result shortcuts, so a private search does not automatically navigate to another website. Normal clickable search results still lead to external destinations, which may receive your visit information. You can select Brave Search, Startpage, or both, but no other search provider.

The source preview action shows selected providers before any search-provider request is made. Continuing, choosing one provider, or using a result-page “Search only” action starts a new POST search that may send your terms to those providers. Preview is not evidence that a source is reachable or trustworthy. Startpage may require solving anti-bot proof-of-work challenges and has not been tested for live availability here.

Preferences saved through the local settings form stay in browser settings for this instance. Importing serialized preferences from a shared URL is disabled, so third-party links cannot silently change selected providers. Primary search results are limited to well-formed HTTP and HTTPS destinations, but embedded media, provider behavior, and user-selected destination sites have not received a full security review.

No independent GoreeCloud index, hosted AI model transmission, persistent user profile, or personal saved-search service is included in this source import.
