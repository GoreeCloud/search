GoreeCloud Search

Privacy and sources

Transparency about what this private VPS Development service does and does not protect.

Which providers receive searches?

GoreeCloud Search uses publicly accessible SearXNG search interfaces with no paid search API subscription. The direct-HTTPS Development service has a tested free-source preset: DuckDuckGo, Bing and Startpage for Web; Bing Images; DuckDuckGo and Bing Videos; and DuckDuckGo News. You can choose All Sources to include all seven configured search-engine families, including Brave Search, Qwant, Ecosia and Google. A provider that blocks or fails is reported instead of silently replaced. Availability is not guaranteed.

The selected external search providers can receive your search terms and see the VPS public IP address. This active free-first Development service uses ordinary direct HTTPS, not Tor or a mandatory SOCKS5H relay. Older, separate private Search/Tor recovery containers remain available but do not serve this hostname. Search providers may log, rate-limit, challenge or reject automated requests under their own policies. The experimental native document index is a separate Development-only opt-in.

What stays on your device?

The chosen search-provider preference and other preferences are stored in your browser's cookies. There is no GoreeCloud personal profile or hosted AI transmission in this Development build. An isolated native Development index can search a small, explicitly approved document corpus when separately enabled; it is not a general-web index and is not automatically combined with All Sources.

Search transport and content

Search terms are submitted by POST instead of being put in the local address-bar URL. Remote autocomplete and anonymous metrics are disabled in this Development profile, and images are proxied. Browser clicks on search results can still send you to third-party sites. Other privacy and security limitations remain.

Development limitations

This Development service is hosted at search-dev.goreecloud.com behind NetBird-only HTTPS access. The front reverse proxy denies non-NetBird clients, and its Search containers have no host-published ports. The upgraded free-search deployment sends upstream requests directly over HTTPS; selected providers can see the server IP and search terms. This service does not promise anonymity or upstream provider availability. The global in-process request budget is 12 search submissions per minute on one worker and is not a distributed public-user limiter. Security, monitoring, independent upstream reliability, and Stable release acceptance remain ongoing work; no paid API account or billing is required.

Technology attribution. GoreeCloud Search builds upon SearXNG, an open-source metasearch project available under AGPL-3.0-or-later. Explore GoreeCloud Search source code. The upstream contributors remain acknowledged; this is not an independent crawler or index.
