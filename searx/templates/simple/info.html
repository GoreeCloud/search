GoreeCloud Search

Search the web on your terms.

A privacy-conscious, open-source search experience using deduplicated results from Brave Search, Startpage, Qwant, DuckDuckGo, Ecosia, Bing and Google.

Choose your sources

{% if get_setting('goreecloud.default_source_choice') == 'working' %}This free-first Development deployment starts with tested free sources, while All Sources remains available.{% else %}All Sources is selected by default, combining approved providers in one deduplicated results page.{% endif %} You can select individual engines in Settings. Your selected services receive your search terms; provider access can be blocked or rate-limited. No automatic replacement provider is added.

Explore more

Use Web, Images, Videos, or News tabs after searching. Some providers offer different types of results; Qwant and Brave provide video searches in this build.

Privacy, not anonymity

Search queries use POST on this private VPS Development service. Your browser, the Search server and selected external search providers may still process connection information. The free-first configuration uses direct HTTPS, not Tor or commercial APIs. Read the Privacy and source disclosure.

Open source foundations

GoreeCloud Search is built on the open-source SearXNG engine, distributed under the AGPL-3.0-or-later license. We recognize its developers and contributors. See the GoreeCloud Search source repository for code and attribution.

Search help

Search shortcuts

!br searches Brave Search, !sp uses Startpage, and !qw uses Qwant. These are explicit requests; no unapproved provider is selected automatically.

Search preferences

Adjust SafeSearch, language and your preferred sources in Settings. A saved setting may override a new installation's defaults.
